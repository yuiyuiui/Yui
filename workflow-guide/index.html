translate

The tool adapter translate receives Audited@2 and returns a named port and its payload.

An uncertain external effect requires a receipt for the same operation before the run continues.

Authors may consult strategy cards. Check helper declarations incrementally, compile the combined proof and audit the export. Every native wall timeout receives a source-located diagnosis. Local checks start at six minutes and rise by six to thirty only for workload findings. Complete-file assembly/export/inspection and final basis closure start at thirty minutes and rise by fifteen to sixty. Code repair retains its current allowance; partial output from a timed-out check cannot pass acceptance. A complete local round may retain GRAPH_ASSEMBLY_REPAIR_REQUIRED while selection, reading and assembly preparation pass its exact bound files to connection repair. Incomplete rounds remain available to diagnosis/reuse under their own gates. Final acceptance requires actual compiled evidence.

Run controls

Faults and recovery

An ordinary execution fault retains its node and diagnostic. An explicit resume retries from the saved state.

For a reconcile effect, inspect the external operation and submit its actual outcome with settle and the matching operation ID.

A visit limit also pauses execution. Resuming the same over-budget activation keeps that limit in force.

Diagram connections
FromPort or actionTo
Execute blockfaultInspect diagnostic
Inspect diagnosticresumeExecute block
Execute blockunknown effectReconcile effect
Reconcile effectsettleExecute block

Delivery, cancellation and cleanup

A business exit records its named result and verifies the published bundle. Cancellation of unfinished work records its own receipt. An already published delivery is recovered if cancellation races with its final commit.

Explicit clean cancels unfinished work, verifies delivery, and removes owned working files. The delivery command can verify the retained bundle afterwards.

Unfinished runcancelCancelled receipt
