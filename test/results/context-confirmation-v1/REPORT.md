## Concrete defects found and repaired

1. **Carrier phase collision.** The text-stage measurement label replaced the
   inherited proof/closing lifecycle state. This silently disabled the declared
   Mathlib search/read tools. The fields are now separate and real dispatch
   controls pass. Ten prior affected text stages have runtime-qualification.json
   sidecars. Their raw results and usage are unchanged, but prior transport-only
   validity does not make them healthy library-enabled timing/capability data.
2. **Relative native probe paths.** A sandbox profile was referenced relative to
   a nested child working directory and could not launch. Stage/case/probe paths
   are now absolute. Real relative-directory query controls pass; native launch
   failures are execution faults, not rejected mathematical candidates.
3. **An inaccessible format example and incomplete format feedback.** The only
   complete old example was in test fixtures, correctly outside the reader's
   allowlist. A neutral complete example is now in templates and is checked
   against the authoring contract. Witness-before-choice and exact application
   field types are explicit. H mismatch feedback explains that the comparison
   is against the author's own submitted spec, not an unseen controller H list.
4. **Repeated signature/hash transcription.** The model repeatedly retyped
   long Lean printer output and evidence hashes, causing ordinary metadata
   mismatches. The controller now binds M metadata from the actual successful
   probe matching ID/declaration/module. Primary NL statements, conditions,
   definitions and arguments are not rewritten. Explicitly omitted duplicate
   H/P/source-restatement aliases may be copied from their primary text;
   conflicting supplied duplicates are rejected, with both source strings shown.
   Canonical NL0 files still satisfy the unchanged complete v2 checker.
5. **A semantic-review weakness.** The first wave packet reviewer marked named
   FTC/Fubini invocations as if they had been proved locally. Its overall report
   was UNVERIFIED, so it never issued an A pass. The rule now explicitly separates
   naming/applying a familiar theorem from proving it. A new fresh reviewer,
   without the old verdict, rejected the same packet's unlisted dependencies.
   This observed improvement is not a guarantee that future reviews cannot err.

The canonical nl0.py and closure.py checkers were not relaxed. Software
validation: 115 core and 107 translation regressions passed (222 total), native
probe/isolation controls passed, and the single skill entry validated. See
rigorous-proof/tests/results/regressions-v5. No old NL2Lean or production skill

not been disproved. Audit A, final target Lean and B were not run.
