Chen's resolvent takes values in \(\operatorname{Dom}(A_t)\), which is not
in general contained in \(\operatorname{Dom}(G)\).  We first verify the
trace used here.  Let \(f\in\operatorname{Dom}(A_t)\), put
\(H=\widehat f|_{(0,\infty)}\), and set

\[
 F(\eta)=e^{it\eta^2}H(\eta).
 \tag{4.8a}
\]

By (0.22), \(F\in H^1(0,\infty)\).  Multiplication by
\(e^{-it\eta^2}\) preserves \(H^1(0,a)\) for every finite \(a\), so
\(H\) has the same trace at zero.  We define

\[
 I_{+,t}(f):=F(0+)=H(0+)
 \tag{4.8b}
\]

and suppress the subscript \(t\).  On
\(\operatorname{Dom}(G)\cap\operatorname{Dom}(A_t)\), this agrees with
(0.11a).

This trace is continuous in the graph norm of \(A_t\).  Indeed, the
absolutely continuous representative of \(F\in H^1(0,1)\) satisfies
\(F(0)=F(x)-\int_0^xF'(\eta)\,d\eta\).  Cauchy--Schwarz, followed by
integration in \(x\in(0,1)\), gives
